# IT-INCUBATOR Counter Project

## React + TypeScript + Vite

Counter application with settings.

## Getting Started

### 1. Install dependencies:

```bash
pnpm i
```

### 2. Start app:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Happy hacking 🚀
